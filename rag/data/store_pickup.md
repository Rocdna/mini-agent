# 门店自提

## 自提适用范围

以下场景建议选择门店自提：

- 所在区域在禁运范围或因天气 / 交通管制暂无法配送；
- 需要尽快拿到商品的急用场景；
- 大宗商品（如家电、家具）希望当面验机。

## 自提流程

1. 下单时选择「门店自提」并指定自提门店；
2. 支付完成后，等待系统通知备货完成；
3. 凭**提货码 + 身份证**到门店提货；
4. 当面验机确认无误后签收。

## 备货时效

- **常见商品（手机、小家电）**：半天内备货完成；
- **大宗 / 需调货商品**：1-3 天，以门店通知为准；
- 备货完成后 7 天内未提货，订单将自动取消。

## 提货须知

- 提货需本人到场，**不可代办**（实名商品如手机例外，可委托直系亲属持双方证件）；
- 逾期未提导致订单取消的，退款按原路退回；
- 门店自提不额外收取费用。

## 门店查询

可在商城「门店自提」页面按城市 / 商圈搜索可用门店，并查看实时备货状态。
