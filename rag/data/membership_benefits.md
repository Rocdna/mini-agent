# 会员权益

## 会员等级

星辰商城会员分为四个等级，由近 12 个月的累计消费金额决定：

- **银卡会员**：累计消费 ¥1,000 及以上；
- **金卡会员**：累计消费 ¥5,000 及以上；
- **铂金会员**：累计消费 ¥20,000 及以上；
- **钻石会员**：累计消费 ¥50,000 及以上。

等级每自然年重新评估一次。

## 等级权益

各等级享受的权益如下：

| 权益 | 银卡 | 金卡 | 铂金 | 钻石 |
|------|------|------|------|------|
| 积分倍数 | 1 倍 | 1.2 倍 | 1.5 倍 | 2 倍 |
| 生日礼包 | ✗ | ✗ | ✓ | ✓ |
| 专属客服 | ✗ | ✗ | ✓ | ✓ |
| 节假日优先发货 | ✗ | ✓ | ✓ | ✓ |
| 免费上门取退 | ✗ | ✗ | ✗ | ✓ |

## 积分规则

- 消费 **¥1 = 1 积分**（银卡基础积分），按等级倍数累积；
- 积分有效期为 **12 个月**，过期作废；
- 积分可在结算时抵扣金额，**100 积分 = ¥1**。

## 积分抵扣限制

积分抵扣金额不得超过订单实付金额的 **50%**，且不可与优惠券叠加使用于同一订单。

## 会员生日礼

铂金及以上会员在生日当月，可领取一张 **¥100 无门槛优惠券**，有效期为领取后 30 天。请提前在「个人中心」完善生日信息，逾期不补。
