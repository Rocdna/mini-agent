# 账号安全

## 密码与登录

- 建议使用**12 位以上**、含大小写字母 / 数字 / 符号的强密码；
- 开启**双重验证（2FA）**可显著提升账号安全；
- 登录异常（异地登录、设备变化）时，系统会下发验证码确认。

## 账号锁定

连续**5 次输入密码错误**，账号将被临时锁定 30 分钟。锁定期间无法登录、无法重置密码。若确因忘记密码，可走「忘记密码」流程通过绑定的手机 / 邮箱重置，无需等待锁定结束。

## 手机 / 邮箱更换

- 更换绑定手机：进入「安全中心 - 手机验证」按流程操作，需验证原手机验证码；
- 更换绑定邮箱同理，需验证原邮箱；
- 更换后旧联系方式即刻失效。

## 异常登录处理

发现账号有可疑操作时（如异常下单、积分被消耗），请立即：

1. 修改密码；登出所有设备；
2. 联系官方客服冻结账号；
3. 提供身份凭证申诉找回。

## 未成年人保护

未满 18 周岁的用户，下单需由监护人确认。商城会通过实名信息校验规避未成年人异常大额消费。
